# Contributing

This project is part of the open-source end-to-end-observability repository and is licensed under MIT.

## Access Request

If you need access to this repository, contact the repository owner.

## For Authorized Contributors

1. Clone the repo (you have permission)
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make changes, commit with clear messages
4. Push and open a pull request
5. Request code review from maintainers

## Guidelines

- Keep research documents updated with new findings
- Test data generation scripts before committing
- Update AZURE_DEPLOYMENT_GUIDE.md if infrastructure changes
- Document any new device types or schemas

## Questions?

Contact the repository maintainer.
